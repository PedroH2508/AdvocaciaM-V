# Montenegro & Vasconcellos Advocacia

Landing page institucional para um escritório de advocacia fictício, desenvolvido com foco em design profissional, experiência do usuário e apresentação clara dos serviços jurídicos.

**Acesse o projeto:** [Montenegro & Vasconcellos Advocacia](https://pedroh2508.github.io/AdvocaciaM-V/)

## Sobre o projeto

O projeto consiste em uma landing page para apresentar o escritório Montenegro & Vasconcellos Advocacia, suas áreas de atuação, sua proposta de atendimento e seus canais de contato.

A interface foi concebida para transmitir profissionalismo, confiança e clareza, proporcionando aos visitantes uma experiência organizada e facilitando o acesso às informações do escritório.

## Funcionalidades

* **Apresentação institucional:** introdução ao escritório e sua proposta de atendimento.
* **Áreas de atuação:** apresentação dos serviços jurídicos oferecidos.
* **Atendimento jurídico:** informações sobre as etapas do atendimento e acompanhamento dos casos.
* **Apresentação dos sócios:** seção dedicada aos profissionais do escritório.
* **Contato:** informações de contato e formulário para envio de mensagens.
* **Atendimento criminal de urgência:** seção específica para orientações sobre situações urgentes.
* **Navegação por seções:** acesso organizado às principais áreas da página.

## Tecnologias utilizadas

* **HTML5:** estruturação semântica do conteúdo.
* **CSS3:** estilização, identidade visual e organização dos elementos.
* **JavaScript:** implementação de comportamentos e interações da interface.
* **GitHub Pages:** hospedagem e publicação do projeto.

## Como executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/pedroh2508/AdvocaciaM-V.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd AdvocaciaM-V
   ```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server do Visual Studio Code para executar o projeto em um servidor local.

## Objetivos do projeto

* Desenvolver uma página institucional com apresentação profissional.
* Aplicar conceitos de UI/UX Design ao contexto de serviços jurídicos.
* Organizar informações de forma clara e acessível.
* Praticar desenvolvimento front-end com HTML, CSS e JavaScript.
* Criar uma experiência digital que facilite a comunicação entre o escritório e seus potenciais clientes.
